# TechnicolorTouchBar

A modern, customizable Touch Bar and Menu Bar utility for macOS.

## Features

### Touch Bar Multi-Page System
* Multiple independent Touch Bar page layouts (Page 1 through Page 4)
* Quick page cycling button on the Touch Bar strip (P1, P2, P3, P4)
* Customizable tile arrangements per page with live previews in Settings

### Stock System Touch Bar Passthrough
* Seamlessly cycle past the final page into the native macOS stock Touch Bar
* Automatic passthrough to frontmost app controls, brightness, and volume sliders
* Dedicated narrow quick-restore button ("TC") anchored to the right edge of the native strip to jump back into TechnicolorTouchBar instantly

### Menu Bar Integration
* Pin up to 8 tiles directly into the macOS menu bar
* Centered placement support on Mac models without a display notch
* Active app switcher pinned to the menu bar with color-coded running app indicators
* Right-click context menus on pinned items for direct Tile Options and unpinning shortcuts

### Live Widgets and System Controls
* Audio Player widget with live album artwork display, play/pause controls, and interactive seek scrubber
* Wide media playback support: Apple Music, Spotify, VLC, Netflix, YouTube, Safari, Chrome
* Hardware monitoring widgets: CPU and RAM usage, battery levels, fan speeds, network throughput, audio output selector
* Weather widget with localized conditions, temperature readings, and detailed forecasts
* Financial stock ticker widget with live price updates
* Built-in Timer, Stopwatch, and Quick Alarm tiles
* Voice dictation toggle with live audio recording tiles
* Animated GIF tile support with customizable playback loops

### Predictive Typing and Smart Reply
* Real-time predictive text bar with multi-word suggestion buttons
* Smart Reply manager with contextual suggestions based on incoming message notifications
* Dedicated Touch Bar emoji picker and full-width emoji keyboard strip

### Productivity Tools
* Global Clipboard History panel triggered via Option-Command-V
* Two-Factor Authentication (2FA) autofill detector and single-tap code insertion tile
* Custom macOS Shortcuts integration with an interactive Shortcut action picker
* Deep link tile options and RGB flow lighting customizations

## Requirements
* macOS 13.0 (Ventura) or newer
* Mac with Touch Bar hardware or supported virtual touch bar display

## Installation
1. Download the latest notarized TechnicolorTouchBar.dmg package.
2. Open TechnicolorTouchBar.dmg.
3. Drag TechnicolorTouchBar.app into your /Applications directory.
4. Launch TechnicolorTouchBar from Applications.
5. Grant Accessibility permissions when prompted to allow Touch Bar rendering and automation shortcuts.

## Security and Verification
TechnicolorTouchBar is built with Hardened Runtime, signed with an official Apple Developer ID certificate, and notarized by Apple Gatekeeper.
